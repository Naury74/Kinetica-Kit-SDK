## 해석

- 노드 2,000개에서도 명령 적용 p95가 0.4ms 안팎으로 docs 15 목표(p95 12ms)보다 훨씬 작다. 검증은 명령마다 문서 전체를 다시 보지만 아직 병목이 아니다.
- JSON 읽기는 노드 2,000개에서 p95가 다른 작업보다 크다(GC 영향). 읽기는 화면 프레임 밖(IO 스레드)에서 한다.
- 실기기 프레임 시간(API 26 기기, 중급·최신 기기)은 아직 재지 않았다. 측정 전까지 성능을 제품 약속으로 쓰지 않는다.

다시 재기: `./gradlew :benchmarks:runBenchmarks` (결과: `benchmarks/build/reports/benchmarks/jvm.md`)
