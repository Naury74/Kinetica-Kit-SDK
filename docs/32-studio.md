# 32 — 화면 편집기 (`KineticaEditor`)

디자이너와 운영자가 앱 안에서 화면과 목업을 만드는 편집기다. 화면 렌더러 `SceneLayout`과 내보내기 렌더러 `drawScene`이 같은 내부 그리기 코드인 ShapeStyle.kt를 쓰므로 화면과 PNG 결과가 같다.
연동 코드는 [연동 예](integration.md#편집기와-저장)에, 장면 구조와 호스트 뷰 배치는 [30 UI 조립](30-ui-composer.md)에 있다.

## 편집 기능

- 선택, 이동, 크기 조절, 회전. 회전했거나 중첩된 노드에서도 반대쪽 핸들은 제자리에 고정된다.
- 빈 곳에서 끌어 사각 영역 선택, 두 손가락으로 이동과 확대, 마우스 휠로 확대.
- 가이드라인 스냅: 다른 노드와 artboard의 가장자리, 가운데에 붙는다. 8dp 안으로 들어오면 붙고, 12dp 밖으로 벗어나야 떨어진다.
- 그룹 만들기와 해제, 정렬과 분배, 쌓는 순서 바꾸기. 그룹을 만들거나 풀어도 화면 위치는 그대로다.
- 속성 패널, 보임과 잠금을 켜고 끄는 레이어 패널, 키보드 단축키. 단축키는 화살표, Shift+화살표, Delete, Esc, Ctrl+Z, Ctrl+Shift+Z다.
- 텍스트를 두 번 누르면 그 자리에서 바로 고친다.
- 사진 선택기로 고른 `content://` 이미지를 넣는다. 큰 사진은 메모리 상한에 맞춰 줄여 읽는다.
- 실행 취소는 제스처 하나를 한 단계로 기록한다. 바뀐 노드만 저장하며 단계 수와 메모리에 상한이 있다.
- 문서는 불변이고 명령으로만 바뀐다. 명령을 적용할 때마다 id, 순환, 깊이, 유한한 숫자, 상한, URI를 검증한다.

여러 노드를 고르면 함께 감싼 테두리에 핸들이 나온다. 끌면 반대쪽 핸들은 그대로 두고 모두 같은 비율로 크기와 위치가 바뀌며,
회전 핸들은 감싼 테두리 가운데를 축으로 모두 함께 돌린다. 코드에서는 `TransformOps.resizeMany`와 `rotateMany`가 맡는다. 실행 취소 한 번으로 되돌아간다.

### 편집기 모양

편집기 색은 `StudioTheme`으로 정한다. 기본은 어두운 테마이고, `StudioTheme.light()`나 시스템 다크 모드를 따르는 `StudioTheme.system()`을 쓸 수도 있다.
편집기 안의 입력란, 칩, 바텀 시트는 호스트 앱의 MaterialTheme이 아니라 이 색을 따른다. 기본으로 들어 있는 문구는 영어와 한국어다. 다른 언어는 같은 이름의 문자열 리소스를 정의해 덮어쓴다.

상단 도구 모음은 추가, 실행 취소, 보기 버튼을 캡슐 모양으로 묶어 둔다. 폭이 모자라면 메뉴 버튼부터 이름을 숨겨 아이콘만 남기고, 그래도 넘치면 가로로 스크롤한다.
`onExit`을 넘기면 나가기 버튼이 스크롤되지 않고 오른쪽 끝에 고정된다. `toolbarEnd`에 넣는 호스트 버튼은 `StudioToolbarButton`과 `StudioToolbarGroup`으로 편집기 버튼과 모양을 맞춘다.
폭이 600dp 이상이면 오른쪽에 레이어 패널과 속성 패널이 붙고, 좁은 화면에서는 도구 줄의 "레이어", "속성" 버튼으로 바텀 시트를 연다.

## 도형

| 도형 | 넣는 곳 | 속성 |
| --- | --- | --- |
| 사각형 | 도구 막대 | 모서리 반지름, 모서리별 반지름 |
| 타원 | 도구 막대 | — |
| 다각형, 별 | 도형 더보기 | 꼭짓점 수 3..64, 별 비율. 별 비율이 1이면 다각형이다 |
| 선, 화살표 | 도형 더보기 | 선 색, 두께, 점선, 화살표나 원으로 정하는 시작과 끝 모양 |
| Frame | 도구 막대 | 모서리별 반지름, 자르기, 오토 레이아웃 |
| 텍스트 | 도구 막대 | 아래 리치 텍스트 참고 |

## 스타일

- 채우기: 없음, 단색, 선형 그라디언트, 원형 그라디언트 가운데 고른다. 선형 그라디언트는 각도를 정한다. 텍스트에도 그라디언트를 쓸 수 있다.
- 선: 색, 두께, 점선 `strokeDash`, 열린 경로의 시작과 끝 모양 `LineCap`을 정한다.
- 효과: 바깥 그림자와 안쪽 그림자를 합쳐 최대 8개까지 넣고, 그림자마다 X, Y, 블러, 퍼짐, 색을 정한다. 레이어 블러도 있다. 화면에서는 API 31 이상이면 노드 전체에 블러를 적용하고,
  그보다 낮은 기기와 PNG 내보내기에서는 도형의 채우기와 선에만 적용하므로 텍스트와 이미지는 흐려지지 않는다.
- 그림자를 `shadow` 하나로만 저장하던 예전 문서도 그대로 읽는다.

## 리치 텍스트

- 텍스트 전체에 글꼴, 굵기, 기울임, 밑줄과 취소선, 줄 높이, 자간을 정한다. 글꼴은 `sans`, `serif`, `monospace`, `cursive`와 호스트 글꼴 가운데 고른다.
- 일부 구간만 바꾸려면 텍스트 편집 창에서 범위를 선택한 뒤 굵게, 기울임, 밑줄, 취소선, 크기, 색, 글꼴을 적용한다. 선택하지 않으면 전체에 적용된다. 입력란에서도 스타일이 그대로 보이고,
  텍스트를 고치면 구간도 따라 움직인다. 구간 끝에서 이어 쓰면 같은 스타일이 적용된다.
- 호스트 글꼴은 문서에 이름만 저장한다. 앱 최상위에서 `CompositionLocalProvider(LocalSceneFonts provides SceneFonts.of(mapOf("brand" to brandFamily)))`로 넘기고,
  내보낼 때는 `PngExporter(context, fonts = …)`로 넘긴다.
- 데이터 바인딩으로 텍스트가 짧아지면 구간을 새 길이에 맞게 잘라서 그린다.
- 상자 크기 방식은 세 가지다. **고정 크기**는 넘치는 부분을 자르고, **높이 자동**은 너비를 유지한 채 줄 수에 맞춰 높이를 바꾸며, **너비 자동**은 자동 줄 바꿈 없이 텍스트 길이에 맞춘다.
  내용에 맞추는 Frame 안에 두면 버튼이나 칩이 텍스트 길이에 따라 늘어난다.

## 내보내기와 목업

- `PngExporter`로 PNG를 만든다. `ExportRequest(widthPx = 1080, mockup = MockupFrame(DeviceFrame.Phone))`처럼 목업을 지정하면 배경과 그림자를 깔고
  기기 프레임 안에 넣어 내보낸다. 기기 프레임은 휴대폰, 폴더블, 태블릿, 브라우저 네 가지이며 코드로 그린 단순한 도형이다.

## 컴포넌트와 디자인 토큰

- 아무것도 선택하지 않으면 속성 패널에 토큰과 컴포넌트 같은 문서 설정이 나온다.
- **컴포넌트 만들기**는 선택한 Frame을 컴포넌트 원본으로 만든다. 여러 개를 선택했으면 Frame으로 감싼 뒤 만든다. **추가**로 인스턴스를 넣으면 원본의 자식이 복사된다.
- 원본을 고치면 모든 인스턴스에 반영된다. 인스턴스에서 직접 바꾼 텍스트나 색 같은 값은 오버라이드로 남아, 원본이 바뀌어도 유지된다.
  인스턴스 속성에는 **메인 컴포넌트로 이동**, **오버라이드 재설정**, **인스턴스 분리**가 있다. 분리한 인스턴스는 일반 Frame이 된다. 인스턴스 크기를 바꾸면 자식은 제약에 따라 움직인다.
- **베리언트**: 컴포넌트 이름이 `Button / Primary`, `Button / Disabled`처럼 `세트/베리언트` 형태이면 같은 세트의 베리언트로 본다. 원본 속성의 **베리언트 추가**는
  원본을 복사해 오른쪽에 새 베리언트를 만든다. 세트에 속하지 않던 원본은 이때 `이름/Default`가 된다. 인스턴스 속성의 베리언트 칩으로 베리언트를 바꾸면
  모양은 새 원본을 따르고, 오버라이드한 텍스트와 색은 레이어 이름 경로가 같은 노드로 옮겨진다.
  세트에 `Pressed`나 `눌림`이라는 이름의 베리언트를 만들어 두면, 재생기에서 동작이 있는 인스턴스를 누르고 있는 동안 그 베리언트로 보인다. Figma의 인터랙티브 컴포넌트와 같은 방식이다.
  오버라이드한 텍스트나 데이터로 바뀐 텍스트는 그대로 유지되고, 손을 떼면 원래 베리언트로 돌아온다.
  인스턴스의 **베리언트 데이터 키**에 키를 적으면 호스트가 `SceneData`에 베리언트 이름을 문자열로 넣어 베리언트를 고른다. 이 연결이 `BoundProperty.Variant`다. 코드에서는 `ComponentVariants`를 쓴다.

  ```kotlin
  // 장면의 결제 버튼 인스턴스에 베리언트 데이터 키 "pay.state"를 바인딩해 둔 경우
  KineticaPlayer(scene, data = SceneData.of("pay.state" to DataValue.Text(if (canPay) "Primary" else "Disabled")))
  ```
- 디자인 토큰은 이름과 색의 쌍이고, 색은 `#RRGGBB`나 `#AARRGGBB`로 적는다. 채우기 아래의 토큰 칩으로 채우기를 토큰에 연결하면 토큰을 바꿀 때 함께 바뀐다.
  색을 직접 고치면 연결이 끊긴다.
- **기본 키트 추가**를 누르면 artboard 오른쪽 바깥에 컴포넌트 원본과 `color.brand` 같은 토큰이 들어간다. 원본은 Primary, Secondary, Disabled 베리언트로 된 버튼 세트와 칩, 카드, 토글, 입력란, 목록 항목, 탭 바다.
  재생기는 artboard 바깥을 그리지 않으므로 이 원본은 화면에 나오지 않는다. 코드에서는 `UiKit.starter(...)`를 쓴다.

## 모션 효과

속성 패널의 **모션 효과**에서 누름 효과, 등장 효과, 반복 효과를 고른다. 누름 효과는 리플, 축소, 기울이기, 어둡게, 떠오르기, 버스트다. 등장 효과는 9종이고 시간과 지연을 정하며, 반복 효과는 11종이고 주기를 정한다.
효과를 고르면 바로 아래 미리보기에서 움직임을 볼 수 있다. 미리보기를 눌러 누름 효과를 시험하고, **다시 재생**으로 등장 효과를 다시 본다.
편집 캔버스에서는 효과가 움직이지 않고 미리보기와 재생기에서만 움직인다. 자세한 내용은 [33 모션 효과](33-effects.md)에 있다.

## 애니메이션

키프레임을 넣을 수 있는 속성은 이동, 배율, 회전, 불투명도, 채우기 색, 선 두께, 너비, 높이, 모서리 반지름, 선 색, 레이어 블러다. 첫 번째 그림자의 블러, X, Y, 퍼짐, 색과
왼쪽 위, 오른쪽 위, 오른쪽 아래, 왼쪽 아래 모서리별 반지름에도 키를 넣을 수 있다.
모서리별 반지름이 있는 노드에서 전체 모서리 반지름을 애니메이션하면, 왼쪽 위 값과의 차이만큼 네 모서리를 함께 움직여 모양을 유지한다.
키는 타임라인 패널의 속성 버튼으로 넣는다. 자동 키를 켜면 속성 패널에서 바꾼 값이 지금 재생 위치에 키로 들어간다. 그라디언트가 있는 노드에서는 그라디언트 시작 색, 끝 색, 각도도 애니메이션할 수 있다.

재생 위치는 프레임마다 시간을 더해 가지 않고 시계를 기준으로 계산한다. 배속, 반복, 왕복, 역방향, marker를 지원하고 '애니메이션 삭제' 설정을 따른다.
easing은 베지어, 계단, 스프링이다. 계단은 CSS `steps()`와 같은 점프 방식 네 가지를 쓴다. 회전은 키마다 가장 짧게, 시계 방향, 반시계 방향, 값 그대로 가운데 방향을 정한다.
여러 노드를 고르고 타임라인 패널 헤더의 **프리셋**을 누르면 차례로 등장하기 같은 모션 프리셋 6종이 나온다. 하나를 고르면 고른 노드 모두에 재생 위치부터 키를 한 번에 넣는다.

### 타임라인 패널

- **확대와 이동**: 두 손가락을 벌리거나 오므리면 손가락 사이 지점을 기준으로 시간 축이 커지거나 작아지고, 옆으로 밀면 가로로 스크롤된다. 마우스에서는 Ctrl+휠이나 Cmd+휠로 확대하고, Shift+휠이나 가로 휠로 스크롤한다. 도구 줄에는 **−**, **+** 버튼과 전체 길이를 한 화면에 맞추는 **맞춤** 버튼도 있다. 처음 배율은 1초가 80dp이고, 그 1/8배부터 25배까지 바꿀 수 있다.
- 눈금자 간격은 배율에 따라 10ms부터 1분까지 바뀌고, 큰 눈금에 `0.25s`, `2s`처럼 시각을 적는다.
- **따라가기**는 기본으로 켜져 있다. 켜 두면 재생 위치가 화면 밖으로 나갈 때 보이도록 스크롤한다.
- **키 선택**: 키를 탭하면 그 키만 고르고 재생 위치가 그 키로 간다. Shift를 누른 채 탭하거나, 길게 눌러 **선택 모드**를 켠 뒤 탭하면 선택에 넣거나 뺀다. 키가 없는 곳에서 가로로 끌면 사각형 안의 키를 고른다. 세로로 끌면 사각 선택 대신 속성 줄 목록이 세로로 스크롤된다. 손가락이 터치 슬롭을 넘는 순간 세로 움직임이 가로보다 크면 스크롤로 본다. 선택 모드에서는 세로로 끌어도 사각 선택이므로, 세로로 긴 범위를 고르려면 길게 눌러 선택 모드를 켠 뒤 끈다. 키 위에서 시작한 끌기는 방향과 상관없이 키를 옮긴다.
- **함께 끌기**: 고른 키 하나를 끌면 고른 키가 모두 같은 시간만큼 움직인다. 0ms 앞이나 타임라인 길이 뒤로 넘어가지 않도록 이동량을 줄인다. 옮긴 자리에 고르지 않은 키가 있으면 `MoveKeyframe` 규칙에 따라 이동 전체를 거부한다. 손을 뗄 때 한 번에 적용하므로 실행 취소 한 번으로 되돌린다.
- 레이어를 고르면 키 줄 위에 키 도구 줄이 늘 같은 높이로 보이며, 여기서 **복사**, **붙여넣기**, **삭제**를 할 수 있다. 고른 키가 없으면 버튼만 꺼지고, 회전 키를 고르면 같은 줄 끝에 회전 방향 칩이 붙는다. 길게 눌러 선택 모드를 켜도 키 줄이 밀리지 않으므로 그대로 이어서 끌면 누른 자리에서 사각 선택이 시작된다. 붙여넣기는 복사한 키 사이의 간격을 유지한 채 가장 이른 키를 재생 위치에 놓고, 지금 고른 레이어에 넣는다. 같은 시각에 있던 키는 새 키로 바꾸고, 타임라인 길이를 넘는 키는 버린다.
- **곡선**: 고른 키 구간의 easing을 고른다. 프리셋은 선형, Ease in, Ease out, Ease in-out, 스프링, 계단(4단계)이다. 선형이나 베지어일 때 그래프의 두 조절점을 끌면 큐빅 베지어가 되며, x는 0..1, y는 -0.5..1.5로 제한한다. 스프링을 고르면 감쇠비 0.05~2와 강성 10~1500 슬라이더가 나온다. 계단을 고르면 칸 수 1~20 슬라이더와 `jump-start`, `jump-end`, `jump-none`, `jump-both` 점프 방식 칩 네 개가 나온다. 점프 방식은 CSS `steps()`와 같고 기본은 `jump-end`다. `jump-none`은 칸이 2개 이상이어야 하므로, 칸이 1개일 때 고르면 칸 수를 2로 올리고 슬라이더도 2부터 움직인다. 칩을 한 번 누를 때마다 실행 취소 한 단계로 남는다. 그래프는 고른 easing의 실제 곡선을 그린다. 스프링은 구간 길이를 시간으로 쓴 진행값이라 1을 넘는 부분도 보이고, 계단은 계단 모양으로 그린다. 그래프 위의 점과 아래 막대는 실제 구간 길이에 맞춰 그 곡선을 따라 움직이며, 이 길이는 0.4~2초로 제한한다. 조절점이나 슬라이더에서 손을 뗄 때마다 결과가 고른 키 모두에 `SetKeyframeEasing`으로 한 번에 들어가며, 실행 취소 한 번으로 되돌린다. TalkBack은 슬라이더의 이름과 "감쇠 0.80" 같은 실제 값을 읽는다. 패널 너비가 720dp 이상이면 키 줄 옆에, 좁으면 키 줄 대신 보인다.
- **단축키**: 타임라인 패널 안을 누르면 패널이 키보드 포커스를 받는다. Delete나 Backspace는 고른 키를 지운다. Ctrl+C는 복사, Ctrl+V는 재생 위치에 붙여넣기, Ctrl+A는 고른 레이어의 키 모두 선택, Esc는 선택 해제다. Ctrl 대신 Cmd를 눌러도 된다. 캔버스에 포커스가 있을 때도 고른 키가 있으면 Delete, Esc, 복사, 붙여넣기가 키에 먼저 적용되고, 고른 키가 없을 때만 Delete가 노드를 지운다.
- **회전 방향**: 고른 키에 회전 키가 있으면 가장 짧게, 시계 방향, 반시계 방향, 값 그대로 중에서 고를 수 있다. 값 그대로는 0에서 720으로 가면 두 바퀴 돈다. 방향은 그 키에서 다음 키까지의 구간에 쓰이고, JSON에는 키프레임의 `rotationDirection`으로 저장된다. 형식은 [34 장면 JSON](34-scene-json.md#타임라인-animations)에 있다.

## 알려진 제한

- 캔버스에서는 최상위 노드 단위로 선택된다. 그룹 안의 노드는 레이어 패널에서 고른다.
- 여러 노드를 함께 크기 조절하면, 회전한 노드는 문서 축 방향의 배율을 자기 축으로 나눠 받으므로 모양이 조금 달라질 수 있다.
- 그룹은 자식을 잘라 내지 않는다. 잘라 내려면 Frame을 쓴다.
- 타임라인 패널에서 키 줄의 빈 곳을 세로로 끌면 스크롤되므로, 사각 선택은 가로로 끌거나 길게 눌러 선택 모드를 켠 뒤 끌어서 시작한다.
- 이미지는 `content://`와 `android.resource://`만 읽고 웹 URL은 열지 않는다. 웹 이미지는 호스트가 받아 둔 뒤 `content://`로 넘기거나 `SceneImageProvider`로 넘긴다.
- SVG와 MP4 내보내기, 협업, 텍스트 shaping 세부 제어는 v1.1 이후에 다룬다.
