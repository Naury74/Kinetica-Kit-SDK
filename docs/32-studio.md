# 32 — 스튜디오 디자인 기능

디자이너·운영자가 앱 화면과 목업을 만드는 편집기(`KineticaEditor`)의 모양·글자·내보내기 기능이다. 화면 렌더러(`SceneLayout`)와
내보내기 렌더러(`drawScene`)가 같은 그리기 함수(`ShapeStyle`)를 써서 결과가 같다.

## 도형

| 도형 | 넣는 곳 | 속성 |
| --- | --- | --- |
| 사각형 | 도구 줄 | 모서리 반지름, 모서리별 반지름 |
| 타원 | 도구 줄 | — |
| 다각형·별 | 도형 더보기 | 꼭짓점 수 3..64, 별 비율(1이면 다각형) |
| 선·화살표 | 도형 더보기 | 선 색·두께·점선, 시작·끝 화살표·원 |
| Frame | 도구 줄 | 모서리별 반지름, 자르기, 자동 배치 |
| 글자 | 도구 줄 | 리치 텍스트(아래) |

## 모양

- 채우기: 없음·단색·선형 그라디언트(각도)·원형 그라디언트. 글자에도 그라디언트를 쓸 수 있다.
- 선: 색·두께·점선(`strokeDash`), 열린 경로의 시작·끝 모양(`LineCap`).
- 효과: 바깥 그림자·안쪽 그림자 여러 개(X·Y·흐림·퍼짐·색, 최대 8개), 레이어 흐림. 화면은 API 31 이상에서 노드 전체를 흐리고,
  그보다 낮은 기기와 PNG 내보내기에서는 모양의 채우기·선만 흐린다(글자·이미지는 흐리지 않음).
- 예전 문서의 그림자 하나(`shadow`)도 그대로 읽는다.

## 리치 텍스트

- 글자 전체: 글꼴(`sans`·`serif`·`monospace`·`cursive`·호스트 글꼴), 굵기, 기울임, 밑줄·취소선, 줄 높이·자간.
- 일부: 글자 수정 창에서 고른 부분(고르지 않으면 전체)에 굵게·기울임·밑줄·취소선·크기·색·글꼴. 입력란에 모양이 보이며
  글자를 고치면 구간이 따라 움직인다(구간 끝에서 이어 쓰면 같은 모양).
- 호스트 글꼴: 문서에는 이름만 저장한다. 앱 맨 위에서 `CompositionLocalProvider(LocalSceneFonts provides SceneFonts.of(mapOf("brand" to brandFamily)))`,
  내보내기는 `PngExporter(context, fonts = …)`.
- 데이터 바인딩으로 글자가 바뀌어 짧아지면 구간은 길이에 맞게 잘라 그린다.
- 상자 크기: **고정 크기**(넘치면 잘림), **높이 자동**(너비 그대로, 줄 수에 맞춤), **너비 자동**(줄을 바꾸지 않고 글자에 맞춤).
  내용 맞춤 Frame 안에 두면 버튼·칩이 글자 길이를 따라간다.

## 내보내기·목업

- `PngExporter`로 PNG. `ExportRequest(mockup = MockupFrame(DeviceFrame.Phone))`면 배경·그림자와 기기 틀(휴대폰·폴더블·태블릿·브라우저)
  안에 넣는다. 틀은 코드로 그리는 일반 모양이다.

## 컴포넌트·디자인 토큰

- 아무것도 고르지 않으면 속성 패널이 문서 설정(토큰·컴포넌트)을 보여 준다.
- **컴포넌트로**: 고른 Frame(여러 개면 Frame으로 감싸서)을 컴포넌트 원본으로 만든다. **넣기**로 인스턴스를 넣으면 원본의 자식이 복사된다.
- 원본을 고치면 모든 인스턴스가 따라간다. 인스턴스에서 직접 바꾼 값(글자·색 등)은 덮어쓴 값으로 남아 원본이 바뀌어도 유지된다.
  인스턴스 속성: **원본으로**, **덮어쓴 값 되돌리기**, **분리**(일반 Frame이 됨). 인스턴스 크기를 바꾸면 자식은 제약대로 따라간다.
- 디자인 토큰은 이름 → 색(`#RRGGBB`·`#AARRGGBB`)이다. 채우기를 토큰에 이으면(채우기 아래 토큰 칩) 토큰을 바꿀 때 함께 바뀐다.
  색을 직접 고치면 연결이 끊긴다.
- **기본 키트 넣기**: 버튼·보조 버튼·칩·카드·토글·입력·목록 항목·탭 바 원본과 `color.brand` 등 토큰을 artboard 오른쪽 밖에 넣는다.
  재생기는 artboard 밖을 그리지 않는다. 코드로는 `UiKit.starter(...)`.

## 애니메이션

keyframe 속성: 이동·배율·회전·불투명도·채우기 색·선 두께에 더해 너비·높이·모서리 반지름·선 색·레이어 흐림·첫 그림자 흐림·첫 그림자 Y.
timeline 패널의 속성 단추로 키를 넣고, 자동 키를 켜면 속성 패널에서 바꾼 값이 재생 위치에 키로 들어간다. 그라디언트 시작·끝 색과 각도도 애니메이션한다(그라디언트가 있는 노드만).
